# Built-in templates

Foundation's built-in templates are compiled into the package and interpreted through the declarative module contract. This directory is retained in published packages as the stable home for future external template resources.

Web starters select the `web-css-reset` module. Its managed `src/styles/reset.css` artifact is the Threadlabs baseline: low-specificity native-element normalization, universal `box-sizing` only, and no universal margin or padding reset.

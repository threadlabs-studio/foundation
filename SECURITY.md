# Security policy

Please report a suspected vulnerability privately through GitHub's security-advisory feature for this repository. Do not open a public issue containing exploit details, credentials, or private repository information.

Include the affected version, impact, a minimal reproduction, and any known mitigation. Maintainers will acknowledge a complete report, assess supported versions, and coordinate disclosure and a release when warranted.

Only the latest released minor line is supported during the initial `0.x` period. Dependency and runtime advisories are reviewed separately from routine freshness updates.
